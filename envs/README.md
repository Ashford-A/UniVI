# Environment files

| File | Use it for |
| --- | --- |
| `univi.yml` | a current environment for the tutorials and new analyses (`conda env create -f envs/univi.yml`) |
| `univi_v0.4.7_env.yml` | rerunning the archived Genome Research notebooks with the release the article was prepared against |
| `univi_v0.5.0.yml` | UniVI 0.5.0 from conda-forge |
| `UniVI_working_environment*.yml`, `univi_env.yml` | full exports of the analysis environments used during development, kept for reference |

For GPU training, install the PyTorch build for your CUDA version (see pytorch.org) into the environment.
