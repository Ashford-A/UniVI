# Notebooks

`GR_manuscript_reproducibility/` contains the notebooks that produced the figures of the Genome Research article, kept exactly as they were run. File names start with `UniVI_manuscript_GR-` followed by the figure they produce. The [reproduction guide](https://univi.readthedocs.io/en/latest/reproducibility/index.html) maps each figure to its notebook and dataset and explains how to rerun them (the article used UniVI v0.4.7; see `envs/univi_v0.4.7_env.yml`). Paths near the top of each notebook point to the original compute cluster and need to be edited for your machine.

`UniVI_additional_examples/` contains further worked examples.

For learning UniVI, start with the tutorials in `docs/tutorials/`, which use the current API and download their data automatically.
